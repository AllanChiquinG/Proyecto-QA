# Proyecto QA - Landing Page de Negocio

## Descripción
Landing page simple (HTML/CSS/JS) desarrollada como caso de estudio para
la aplicación de un proceso de Aseguramiento de la Calidad del Software:
Matriz CTQ, Definition of Done y Quality Gate automatizado con GitHub Actions.

## Objetivo
Demostrar la trazabilidad entre necesidades de negocio, características
críticas de calidad (CTQ), criterios de completado (DoD) y validación
automática mediante un Quality Gate en cada Pull Request.
