# Definition of Done (DoD)

## DoD para Historia de Usuario
- [ ] Criterios de aceptación claros y verificables.
- [ ] CTQ asociado identificado (CTQ-001, CTQ-002 o CTQ-003).
- [ ] Código implementado en rama de trabajo (feature/*).
- [ ] Pruebas manuales documentadas (ej. carga en móvil y escritorio).
- [ ] Evidencia registrada en el issue correspondiente.

## DoD para Pull Request
- [ ] PR vinculado a un issue del backlog.
- [ ] Quality Gate ejecutado en GitHub Actions.
- [ ] No existen fallas críticas abiertas (enlaces rotos, errores de consola).
- [ ] README o documentación actualizada si cambia el comportamiento del sitio.
- [ ] Revisión de al menos un integrante del equipo antes del merge.

## DoD para Sprint/Release
- [ ] CTQs Must (CTQ-001, CTQ-002) completados o justificados si no se cumplen.
- [ ] Deuda técnica pendiente registrada como issue.
- [ ] Evidencias consolidadas en docs/quality/QualityGate.md.
- [ ] Versión etiquetada (tag) o release note preparada.
